مسار | من المعرفة إلى القدرة — From Knowledge to Capability

هذه الصفحة بروفايل تفاعلي مُعَدّ للشركاء والزوار للاطلاع على مكونات مسار الجاهزة والقيد التطوير. تصفّح البطاقات أدناه — كل قسم يجيب عن سؤال محدد: ماذا تملك مسار الآن؟ ما الجاهز للاستخدام مباشرة؟ وما الذي لا يزال نموذجاً أولياً (Demo)؟ الأصول البحثية الأساسية (بنوك المهارات وأداة التقييم الكاملة) غير منشورة هنا حفاظاً على الملكية الفكرية.

القسم الأول — منتجات وأدوات مسار المستقلة

القسم الثاني — حلول مسار للمدارس

الطريقة التي تتجمع بها الأدوات لتكوين حل مدرسي متكامل، تتمحور حول حزمة المدرسة الدامجة (التعليم الشامل).

مسار الحل المدرسي الكامل:   جاهزية المدرسة ← دعم المعلم ← دعم الطالب ← المهارات ← الخطة الفردية ← الإجراء ← المتابعة ← القرار

🏫 حزمة المدرسة الدامجة (التعليم الشامل) — MASAR Inclusive School Package

ملاحظة تنظيمية: الدورات التدريبية لا تُعرض كقسم مستقل — بل تندرج كأول مكوّن (01_Courses) داخل حزمة المدرسة الدامجة، لأنها جزء من مسار الحل المدرسي المتكامل أعلاه وليست منتجاً قائماً بذاته.

هيكل المستودع

المستودع منظم حسب القيمة التجارية والاستخدام، ضمن قسمين رئيسيين فقط — كما هو معروض أعلاه. لمن يفضّل تصفح الملفات مباشرة عبر GitHub بدل هذه الصفحة، يمكن فتح صفحة المستودع حيث يظهر نفس التقسيم في ملف README مع جداول وشارات ملونة أيضاً.
