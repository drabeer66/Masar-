# MASAR Demos Profile | بروفايل مسار للنماذج التفاعلية

**من المعرفة إلى القدرة | From Knowledge to Capability**

## ما هذا الملف؟ (للزائر/الشريك)

هذا المستودع هو **بروفايل تفاعلي** أعدّته MASAR (مركز مسار للتعلّم والمهارات) ليطّلع من خلاله الشركاء والمهتمون على مكونات مسار الفعلية: الأدوات المستقلة، وحزمة المدرسة الدامجة الكاملة — دون الحاجة لعرض تقديمي منفصل.

**كيف تستخدمه؟**
1. افتح رابط العرض المباشر: **https://drabeer66.github.io/Masar-/**
2. الصفحة الرئيسية مقسّمة إلى **قسمين رئيسيين** فقط، كل بطاقة فيها رابط تفتحه مباشرة في المتصفح.
3. راقب شارة الحالة على كل بطاقة (🟢 جاهز / 🔵 Demo / 🟡 تحت التطوير) لتعرف طبيعة كل عنصر قبل فتحه.
4. لتصفح الملفات مباشرة دون المرور بالصفحة الرئيسية، يمكنك أيضاً تصفح مجلدات المستودع أدناه.

> 🔒 **ملاحظة مهمة:** الأصول البحثية الجوهرية لمسار — بنك المناهج، البنك الخاص لذوي الاحتياجات الخاصة، وأداة تقييم النمو المبكر والكشف عن الموهبة الكاملة — **غير منشورة في هذا المستودع**. هذه أصول ملكية فكرية محمية، غير معروضة للبيع أو الاطلاع العام. ما يظهر هنا هو النماذج والأدوات والمنتجات المشتقة منها فقط.

## هيكل المستودع

المستودع منظم حسب **القيمة التجارية والاستخدام**، ضمن **قسمين رئيسيين**:

```
MASAR/
├── index.html                                  ← بوابة الدخول (MASAR Demos Profile)
├── README.md                                   ← هذا الملف
│
├── 01_MASAR_TOOLS_PRODUCTS/                    ← القسم الأول: منتجات وأدوات مستقلة
│   ├── Assessment_Tools/                       (براعم)
│   ├── Educational_Content/                    (المخطط التعليمي القائم على الأدلة)
│   ├── IEP_Planning/                           (أداة إعداد الخطة الفردية - Demo)
│   ├── Monitoring_Tools/                       (لوحة متابعة الطالب والمدرسة)
│   └── Interactive_Kids_Content/                (قصص وأنشطة تفاعلية للأطفال)
│
└── 02_MASAR_SCHOOL_SOLUTIONS/                  ← القسم الثاني: حلول المدارس
    └── Inclusive_School_Package/                ← حزمة المدرسة الدامجة (التعليم الشامل)
        ├── 01_Courses/                          (الدورات التدريبية الأربع)
        │   ├── Course_01_Inclusive_Education/
        │   ├── Course_02_Differentiated_Classroom/
        │   ├── Course_03_Accommodations_Modifications/
        │   └── Course_04_Supporting_My_Child/
        ├── 02_School_Inclusion_Readiness_Toolkit/
        ├── 03_Teacher_Support_Toolkit/
        ├── 04_Parent_Support_Toolkit/
        └── 05_Monitoring_and_Evidence/
```

**ملاحظة على القرار التنظيمي:** الدورات التدريبية الأربع لا تُعرض كقسم منفصل — بل تندرج كأول مكوّن (`01_Courses`) داخل **حزمة المدرسة الدامجة**، لأنها جزء من مسار الحل المدرسي المتكامل (جاهزية ← معلم ← طالب ← مهارات ← خطة فردية ← إجراء ← متابعة ← قرار)، وليست منتجاً قائماً بذاته.
