# MASAR Demos Profile | بروفايل مسار للنماذج التفاعلية

**من المعرفة إلى القدرة | From Knowledge to Capability**

## ما هذا الملف؟ (للزائر/الشريك)

هذا المستودع هو **بروفايل تفاعلي** أعدّته MASAR (مركز مسار للتعلّم والمهارات) ليطّلع من خلاله الشركاء والمهتمون على مكونات مسار الفعلية: الأدوات، الحلول المدرسية، والدورات التدريبية — دون الحاجة لعرض تقديمي منفصل.

**كيف تستخدمه؟**
1. افتح رابط العرض المباشر: **https://drabeer66.github.io/Masar-/**
2. ستصلك صفحة رئيسية (بروفايل) مقسّمة إلى 3 أقسام واضحة، كل بطاقة فيها رابط تفتحه مباشرة في المتصفح.
3. راقب شارة الحالة على كل بطاقة (🟢 جاهز / 🔵 Demo / 🟡 تحت التطوير) لتعرف طبيعة كل عنصر قبل فتحه.
4. لتصفح الملفات مباشرة دون الصفحة الرئيسية، يمكنك أيضاً تصفح مجلدات المستودع نفسه أدناه.

> 🔒 **ملاحظة مهمة:** الأصول البحثية الجوهرية لمسار — بنك المناهج، البنك الخاص لذوي الاحتياجات الخاصة، وأداة تقييم النمو المبكر والكشف عن الموهبة الكاملة — **غير منشورة في هذا المستودع**. هذه أصول ملكية فكرية محمية، غير معروضة للبيع أو الاطلاع العام. ما يظهر هنا هو النماذج والأدوات والمنتجات المشتقة منها فقط.

## دليل شارات الحالة

| الشارة | المعنى |
|---|---|
| 🟢 جاهز | منتج/أداة جاهزة للاستخدام أو العرض المباشر |
| 🔵 Demo | نموذج أولي توضيحي، غير متصل بالبيانات أو الأصول الحقيقية الكاملة |
| 🟡 تحت التطوير | مسودة قيد المراجعة |

## نقطة تواصل

للاستفسار عن الشراكات أو الحلول المؤسسية، يرجى التواصل مع فريق MASAR.
